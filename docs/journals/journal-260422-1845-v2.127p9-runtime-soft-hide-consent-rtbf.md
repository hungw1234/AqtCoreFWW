## Notes & Lessons

1. **`SET QUOTED_IDENTIFIER ON`** — bắt buộc cho mọi script SQL chạm bảng có indexed view/computed column. EF Core default ON, sqlcmd default OFF — gây Msg 1934 nếu thiếu. Đã ghi vào script comment.
2. **5-layer hide pattern** (1.fe-fallback, 2.fe-admin, 3.be-seeder, 4.db-row, 5.redis-cache) — hide menu hoàn chỉnh cần hit ÍT NHẤT L4+L5 (runtime authority). L1-L3 chỉ là dead code chống regression khi reset/refactor.
3. **Idempotent script** — `AND [IsActive] = 1` clause cho phép re-run an toàn (skip rows đã off, không noise log).
4. **Soft-hide vs Hard-delete** — chọn soft-hide vì admin `/admin/menus` vẫn thấy row (đánh dấu inactive) → reviewer audit dễ; bật lại 1 câu UPDATE.
