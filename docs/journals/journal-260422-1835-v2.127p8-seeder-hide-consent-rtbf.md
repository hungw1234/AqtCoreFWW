# v2.127p8 — Tạm ẩn `consent` + `admin-rtbf` trong BE Seeder

## Context

Audit đa layer (turn trước) phát hiện v2.127p4/p5 chỉ ẩn FE hardcoded fallback. DB-driven sidebar vẫn serve 2 menu này cho user có quyền. User yêu cầu "chỉ tạm ẩn cho FE và BE thôi" (không đụng DB runtime).

## Root Cause (carry từ audit trước)

| Layer | `consent` pre-p8 | `admin-rtbf` pre-p8 | Ý nghĩa |
|---|---|---|---|
| L1 FE `sidebar-menu.tsx` | ✅ comment v2.127p5 | — | Chỉ hiệu lực khi API rỗng |

| **L3 BE seeder `E2ETestDataSeeder.Menus.cs`** | ❌ active | ❌ active | **Fix này** |
| L4 DB `[identity].[AppMenus]` | ❌ `IsActive=1` | ❌ `IsActive=1` | Không fix (user skip) |
| L5 Redis cache `menu-tree:*` | ❌ reflect DB | ❌ reflect DB | Không fix (user skip) |

## Limitation (intentional — user explicit skip)

DB hiện có vẫn giữ 2 row active:

```sql
Code       | IsActive | TenantId
admin-rtbf | 1        | NULL
consent    | 1        | NULL
```

Seeder idempotent theo `MenuDashboardId` (L97 `if (await db.AppMenus.AnyAsync(m => m.Id == MenuDashboardId, ct)) return`) → **lần khởi động tiếp theo không reseed** → runtime sidebar vẫn hiện menu. Để thực sự ẩn:

**Option runtime cleanup (user tự chạy khi cần):**
```sql
-- SQL Server auth sa
DELETE FROM [identity].[MenuRolePermissions]
  WHERE [MenuId] IN ('60000000-0000-0000-0000-000000000076', '60000000-0000-0000-0000-000000000010');
DELETE FROM [identity].[AppMenus]
  WHERE [Code] IN ('admin-rtbf', 'consent');
```
+ flush Redis: `redis-cli KEYS 'menu-tree:*' | xargs redis-cli DEL`

## Notes & Lessons

1. **Hide đa-tầng cần đồng bộ L1+L3 tối thiểu** — v2.127p4/p5 comment L1/L2 không đủ với DB-driven menu. Bài học gom vào: khi hide menu tương lai, phải sửa cả seeder + SQL hoặc chấp nhận limitation "chỉ apply fresh DB".
2. **Trade-off tách patch** — ship p7 (logic fix) + p8 (chore hide) riêng biệt cho audit trail rõ. Nếu gộp, changelog mô tả sẽ lẫn scope.
3. **GUID constants giữ lại** — pattern "soft delete trong code" tương đồng v2.127p4/p5: uncomment 4 dòng + reseed = bật lại, không mất reference.
